# Contributor Covenant Code of Conduct

This project is open to everyone who wants to learn, build, or improve something together.
Let’s keep it friendly and productive.

## What’s Expected

* Be respectful and constructive.
* Keep discussions technical and polite.
* Help others when you can, and be open to feedback.

## What’s Not Cool

* Rude or dismissive comments.
* Personal attacks or harassment.
* Spamming or off-topic noise.

## If Something Happens

If someone’s behavior crosses the line, maintainers may edit or remove comments, or block further interaction if needed.
No drama — just keeping things civil.

---

Open source works best when we treat each other well.
